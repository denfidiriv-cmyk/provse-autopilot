# PROВсе motion kit: як монтувати ролик

Готовий приклад повного ролика: `templates/kit/EXAMPLE.html` (економіка, 5 сцен). Прочитай його перед роботою.

## Порядок

```bash
python tools/cc_align.py job/                         # ОБОВ'ЯЗКОВО: точний час слів через розпізнавання мови (після atempo)
python tools/kit_new.py job/ work/hf --bg "#0d1b2a"     # заготовка з субтитрами-караоке
# дописуєш сцени між <!--SCENES--> і <!--/SCENES-->, анімацію між //TIMELINE і ///TIMELINE
python tools/kit_render.py job/ work/hf job/mix.wav      # рендер -> job/final.mp4 + job/check.jpg + job/check_motion.jpg
```
Після рендеру ОБОВ'ЯЗКОВО подивись `job/check.jpg` і `job/check_motion.jpg` (Read), виправ і перерендер. Мінімум одна ітерація виправлень, і після КОЖНОГО перерендеру знову дивись обидва аркуші.

## Граматика монтажу (обов'язково)

1. **Сцени.** 4–6 сцен за 15–22 с, кожна 2–4 с, тривалість нерівна. Склейка завжди на слові: `T(i) - .05`, де i це слово, з якого починається нова думка.
2. **Перший кадр.** Хук-цифра/факт у кінцевому стані з t=0, без анімації входу. На хуку лише рух: `Kit.drift` фону й цифри, `Kit.punch` на найсильнішому слові.
3. **Жодного статичного кадру довше 0,8 с.** У кожній сцені щось рухається: drift фото/фону, поява елементів по словах, лічильник, маркер, стовпчики.
4. **Кожен візуальний акцент прив'язаний до слова.** Елемент з'являється за 0–0,1 с до слова, яке про нього говорить (`T(i) - .08`). Цифра в кадрі = цифра, яку диктор саме вимовляє.
5. **Склейки чергуй.** Не більше двох однакових підряд. `whip` для «але/проте», `zoom` для удару/цифри, `push`/`slideUp` для «далі/ще», `flash` для шоку, `iris` для відкриття. Удар і шок підсилюй `Kit.shake` або `stamp`.
6. **Петля.** `Kit.loop(tl, "#останняСцена", "#s1", END)`: останній кадр збігається з першим.
7. **Розмітка кадру 1080×1920.** Основний вміст у зоні y 150–1150 і займає її сміливо: великі цифри 180–260 px, заголовки 56–72 px, картки на всю ширину 900–960 px. Субтитри живуть у зоні y 1240–1570 (не клади туди нічого). Нижні 320 px і праві 120 px порожні. Верх 0–140 px порожній, без маленьких міток.
8. **Заголовки сцен.** Жодних дрібних підписів угорі кадру. Пояснювальний рядок (56–72 px) стоїть під або над головним елементом у зоні y 200–1150, а не на самому верху. Одна сцена = один головний елемент + максимум один пояснювальний рядок.
9. **Склейки без накладань.** Попередня сцена повністю зникає на склейці (`Kit.cut` це робить). Не анімуй елементи старої сцени після склейки і не вмикай дві сцени одночасно вручну.
10. **Контраст.** Текст завжди на плашці/картці або з тінню; мінімум 40 px. Один акцентний колір + один колір для ключових слів. Шрифти з `assets/fonts`: Osw (цифри), UI (Inter 800, текст), PF (редакторський), JB (табло), Cav (рукописний), Gar (класика).
11. **Логотипи організацій.** Якщо в історії є компанія, банк, відомство чи клуб, вставляй їхній справжній логотип: `python tools/cc_logo.py "<назва англійською> logo" work/hf/assets/img/` (лише суспільне надбання або вільна ліцензія). Ставиш БЕЗ картки й фону: прозорий PNG/SVG прямо на тлі, з легкою тінню (`filter:drop-shadow`). Залиш лише значок/емблему (обріж viewBox у SVG або кадр у PNG, білий фон перетвори на прозорість), бо назва й так з'являється текстом. З'являється разом зі словом, що називає організацію. Якщо назва звучить і виводиться текстом, обріж лого до значка. Підпис «Логотип: Wikimedia Commons, …» дрібно внизу зони вмісту.
11a. **Фото.** `<div class="photo"><img src="assets/img/p1.jpg"><div class="credit">Фото: …</div></div>` + `Kit.drift(tl, "#ph img", t0, t1, {to:1.12})`. Фото завжди рухається.
12. **Текст = субтитри.** Окремої смуги субтитрів немає. Текст у сценах виводь через `Kit.say(tl, "#box", i0, i1, {keys, map})`: кожне слово з'являється тоді, коли диктор його вимовляє, і не дублюється ніде. Цифри показуй цифрами через `map` (напр. `{11: "100%", 12: ""}`). У kit_new прибери виклик `Kit.captions`.
12a. **Старі субтитри (Kit.captions).** Уже підключені: слово вистрибує в момент вимови, активне жовте, ключові червоні. Передай у `Kit.captions` `keywords` (3–8 основ ключових слів: цифри, «менше», «вперше», імена). За замовчуванням субтитри на темній плашці (фраза приглушено, слово спалахує вчасно); `plate: false` лише для дуже темного однорідного фону. Колір під стиль: `accent`, `key`.

## API (assets/kit.js)

| Виклик | Що робить |
|---|---|
| `T(i)`, `Kit.find("основа")` | час слова i; індекс слова за початком |
| `Kit.in(tl, sel, t, kind)` | вхід: `pop rise drop slideL slideR wipe wipeUp blur stamp zoomIn flip lines` (`lines` для `.mask>.line`) |
| `Kit.stagger(tl, sel, t, kind, gap)` | кілька елементів по черзі |
| `Kit.out(tl, sel, t, kind)` | вихід: `fade up down shrink left right` |
| `Kit.cut(tl, from, to, t, kind)` | склейка сцен: `hard whip zoom push slideUp flash iris` |
| `Kit.drift(tl, sel, t0, t1, {to, x, y})` | повільний наїзд/зсув |
| `Kit.punch(tl, t, 1.07)` | різкий наїзд камери на слові |
| `Kit.shake(tl, "#cam", t, 12)` | тряска на удар |
| `Kit.count(tl, sel, 0, 3900, t, .8)` | лічильник (для цифр не в хуку) |
| `Kit.mark(tl, ".marker", t)` | маркер під словом |
| `Kit.bars(tl, ".bar", t)` | стовпчики графіка |
| `Kit.draw(tl, "svg path", t)` | лінія малюється |
| `Kit.flash(tl, t)` | білий спалах |
| `Kit.loop(tl, last, first, END)` | петля на перший кадр |

Не пиши власні setTimeout/requestAnimationFrame/CSS-анімації: усе тільки через `tl`, інакше рендер покадрово зламається.
