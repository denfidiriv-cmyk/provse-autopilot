# Трендові шорти «Все про …»: як робимо і що зараз заходить

## Підготовка свіжої сесії
- `pip install --break-system-packages sherpa-onnx numpy scipy pillow` (якщо бракує).
- Модель для вирівнювання слів (у git її немає): `mkdir -p tools/asr && cd tools/asr && curl -sSL https://github.com/k2-fsa/sherpa-onnx/releases/download/asr-models/sherpa-onnx-nemo-parakeet-tdt-0.6b-v3-int8.tar.bz2 | tar xj`.
- Робочі файли (src, jobs, img, vid) тримати поза репо, наприклад у /tmp/trend/<дата>/. Шляхи в json-специфікаціях абсолютні.
- Публікація через Chrome (YouTube Studio): youtube.com/channel_switcher → клік по «Все про …» (якщо Studio показує інший канал, повторити або «Змінити обліковий запис» на сторінці помилки) → studio.youtube.com/channel/<ID>/videos/upload?d=ud → file_upload з /mnt/user-data/uploads/out (≤10 МБ) → назва, опис, «не для дітей», Далі ×3, «Для всіх», «Опублікувати» (на вікні «Ми все ще перевіряємо» натиснути «Усе одно опублікувати»).

## Процес (одне відео)
1. Тема: Google Trends (Україна, 24 год) https://trends.google.com/trending?geo=UA&hours=24 + тренди X (https://trends24.in/ukraine/) + швидкі українські Shorts (vidIQ trending, мова uk, recentVphEngaged). Тему беремо з Google Trends, X і YouTube лише підтверджують і дають формат.
2. Факти з 2+ джерел, перевірити, що новина справді відповідає тренду. Одне джерело: «за даними …».
3. Голос: workflow voice.yml (name, voice, model, style, text). Голоси: Політика Puck, Економіка Charon, Світ Zephyr, Їжа Aoede, Авто Iapetus, Спорт Fenrir. Якщо 429 на основній моделі: model=gemini-3.8-flash-lite-tts. Запускати з паузою 20-60 с між відео.
4. src: voice.wav сповільнити `ffmpeg -af atempo=0.95`, час слів поділити на 0.95, покласти script.txt. attic_short.py сам вирівнює час слів через tools/cc_align.py (справжнє розпізнавання; без цього субтитри розходяться з голосом до 1,5 с).
5. Фото з Wikimedia Commons (fetch_assets.yml, 1920px thumb), кліпи Pixabay (fetch_pexels.yml). Жодних фото публічних осіб.
6. Специфікація docs/trend_shorts/<name>.json, рендер `bash tools/trend_short.sh <name>`, перевірити sheet.jpg.
7. Опис: тема, посилання на Trends, джерела, автори фото, музика, 4-8 хештегів. Публікація лише після «так» власника.

Висновки для наших каналів:
- Найбільше набирають дуже короткі ролики, 8-16 с, про одну подію дня. Тримати сценарій 30-40 слів.
- Малі канали отримують сотні тисяч, коли першими реагують на головну подію дня. Швидкість важливіша за шліфування: гарячу тему робити протягом кількох годин.
- Заголовок: КАПС на ключових словах, знак оклику, конкретика (цифра, місце), одне емодзі на початку.
- Пояснення «як влаштовано» з 3D або схемою тримає навіть 2,5 хв: для нас це карти, схеми й розрізи замість стокових кліпів.
- Мем або легкий гумор на тему дня працює окремо від новин, коли подія позитивна для українців.
- Теми, які збігаються в Google Trends і X одночасно (сьогодні GTA 6, Сі і Шеньчжень), беремо першими.
