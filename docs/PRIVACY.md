# PROVse Autopilot: Privacy Policy

PROVse Autopilot is a private tool used only by the owner of the PROВсе Production YouTube channels to upload their own Shorts to their own channels and to read those channels' statistics.

- The tool requests access to YouTube only for the owner's channels: uploading videos, changing their privacy status and reading YouTube Analytics.
- No data about other users is collected, stored or shared.
- OAuth tokens are stored only as encrypted GitHub Actions secrets of the owner's repository.
- Channel statistics are used only to improve future videos and are not shared with third parties.
- Access can be revoked at any time at https://myaccount.google.com/permissions.

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Contact: through the repository's issues page.
