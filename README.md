# PROВсе Autopilot

Програма, яка веде мережу YouTube Shorts каналів «Все про …»: тренди, сценарій, озвучка, анімація, субтитри, мікс, завантаження на YouTube і тижнева аналітика.

Як почати: клонуй репозиторій, відкрий папку в Claude Code і напиши «Прочитай CLAUDE.md і збери пілот для каналу «Все про політику»». Правила й архітектура в `CLAUDE.md`, ручний конвеєр у `docs/PIPELINE_NOTES.md`.

## Агент трендів (працює вже зараз, без LLM і без кредитів)

`run_trends.py` читає відкритий RSS Google Trends для України, розкладає тренди по семи каналах за ключовими словами з `config/channels.json`, відкидає негатив (вбивства, смерті, казино) і вже бачені за 3 дні теми, рахує незалежні джерела в Google News і шле звіт у Telegram. Лише стандартна бібліотека Python 3.10+.

1. Встанови Python 3.10+ (галочка «Add to PATH»).
2. Поклади папку в `C:\Users\<ти>\provse-autopilot`.
3. Створи бота в @BotFather, скопіюй `.env.example` у `.env` і впиши `TELEGRAM_BOT_TOKEN` та `TELEGRAM_CHAT_ID` (його дасть @userinfobot).
4. Перевір: `python run_trends.py`. Звіт з'явиться в Telegram і в `out/`.
5. Автозапуск кожні 3 години: Планувальник завдань → Імпортувати завдання → `scheduler/provse_trends.xml`.

Ключові слова каналів правиш у `config/channels.json`: `основа` ловить початок слова, `=слово` лише точне слово, фраза з пробілом шукається цілою. Тести: `python -m unittest tests.test_trends`.
