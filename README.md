# PROВсе Autopilot

Програма, яка веде мережу YouTube Shorts каналів «Все про …»: тренди, сценарій, озвучка, анімація, субтитри, мікс, завантаження на YouTube і тижнева аналітика.

Як почати: клонуй репозиторій, відкрий папку в Claude Code і напиши «Прочитай CLAUDE.md і збери пілот для каналу «Все про політику»». Правила й архітектура в `CLAUDE.md`, ручний конвеєр у `docs/PIPELINE_NOTES.md`.
